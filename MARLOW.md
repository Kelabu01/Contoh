# Marlow — Project Conventions

The build rules — stack selection, database defaults, UI & interaction laws, and visual style —
are defined authoritatively in the system guidance, which is always in context. **This file does
not restate them**, to avoid drift and contradiction between the two.

Use MARLOW.md only for conventions specific to a product or customer that the system guidance does
NOT already cover — e.g. a required brand palette, a domain glossary, or an integration contract.
None are defined yet; add them here as they come up.
